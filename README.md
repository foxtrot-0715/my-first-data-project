# 🗂️ MDM AI Lakehouse Core (MVP)

**Микросервис интеллектуальной дедупликации и нормализации мастер-данных (НСИ) предприятия на основе векторного семантического поиска в пространстве $L_2$-гиперсферы.**

---

## 🎯 Проблема бизнеса
В крупных Enterprise-холдингах (Сбер, Сибур, Х5) разрозненные ERP-системы заваливают справочники номенклатуры дубликатами вида:
1. `Подшипник 6204 D=20`
2. `ПОДШИПНИК ШАРИКОВЫЙ 20Х47Х14`
3. `Подшипн. рад. 6204-2rs \xa0`

Классические алгоритмы нечеткого сравнения строк (расстояние Левенштейна) здесь захлебываются. Ручной разбор миллионных баз стоит бизнесу десятки миллионов рублей ежегодно.

---

## 💡 Решение (Under the Hood)
Пайплайн нормализации сырой строки построен на 3 уровнях:
1. **Глубокая очистка (Deep Clean):** На этапе EDA отловлен скрытый системный баг выгрузок 1С — неразрывные пробелы (`\xa0`), ломавшие распределение токенов. Внедрен жесткий Regex-препроцессинг.
2. **Векторизация:** Легковесная семантическая модель `cointegrated/rubert-tiny2` (весом всего 45 Мб) с усечением длины последовательности до 48 токенов ради ускорения матричных вычислений на 25%.
3. **Математическое ядро:** Проекция косинусного пространства эмбеддингов на единичную гиперсферу через $L_2$-нормализацию признаки. Классификатор `LinearSVC` на тестовом полигоне показал взрывной рост метрики **$F_1\text{-weighted}$ до 0.8159**.

* **[x] 3. Реализовать REST интерфейс:** Асинхронный **FastAPI** бэкенд (`app/api/endpoints.py`: `POST /api/v1/normalize` и `GET /api/v1/stats`).

* **[x] 5. Обеспечить покрытие тестами:** Интеграционные тесты API и Regex-чистильщика на **pytest** (`tests/test_service.py`).
