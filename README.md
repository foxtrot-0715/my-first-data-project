# 🗂️ MDM AI Lakehouse Core (MVP)

**Микросервис интеллектуальной дедупликации и нормализации мастер-данных (НСИ) предприятия на основе векторного семантического поиска в пространстве $L_2$-гиперсферы.**

В крупных Enterprise-холдингах разрозненные ERP-системы заваливают справочники номенклатуры дубликатами. Классические алгоритмы нечеткого сравнения (расстояние Левенштейна) здесь захлебываются. Данный AI-микросервис автоматизирует нормализацию таких строк, экономя бизнесу десятки миллионов рублей.

## 💡 Архитектура и Решение
Пайплайн нормализации сырой строки построен на 3 уровнях:
1. **Глубокая очистка (Deep Clean):** Жесткий Regex-препроцессинг для удаления системного мусора (например, скрытых багов выгрузок 1С вроде неразрывных пробелов `\xa0`).
2. **Векторизация:** Легковесная семантическая модель `cointegrated/rubert-tiny2` (весом всего 45 Мб) с усечением длины последовательности до 48 токенов ради ускорения матричных вычислений на 25%.
3. **Математическое ядро:** Проекция косинусного пространства эмбеддингов на единичную гиперсферу через $L_2$-нормализацию. Поиск и классификация эталонов через алгоритм `LinearSVC`.

## 🤖 Использование AI-Агентов в разработке
Для ускорения цикла разработки (Time-to-Market) в качестве AI-агента применялась модель **Google Gemini Pro**:
* **Генерация данных:** Создание 50+ синтетических edge-кейсов (специфический складской сленг, аббревиатуры, искаженный синтаксис) для стресс-тестирования математического ядра.
* **Архитектурный ревью:** Валидация безопасного CAST для SQLAlchemy и отладка синтаксических конфликтов при работе с векторным расширением `pgvector`.
* **Результат:** Экономия ~20 часов рутинной работы и повышение отказоустойчивости прототипа.

**2. Настройка переменных окружения**

✅ Инфраструктура и стек

    Контрактная модель: Строгая типизация на Pydantic v2.

    СУБД: Хранение данных на SQLite + SQLAlchemy 2.0 (сохранение истории матчинга в nomenclature_audit_log).

    REST API: Асинхронный FastAPI бэкенд (маршруты /api/v1/normalize и /api/v1/stats).

    Интерфейс: Аналитический Web-UI дашборд на Streamlit с индикаторами уверенности.

    Контейнеризация: Оптимизированный Dockerfile (база python:3.11-slim, PyTorch CPU-only).

    Масштабирование: Запуск через Gunicorn с 4 асинхронными Uvicorn-воркерами для горизонтального скейла инференса.
