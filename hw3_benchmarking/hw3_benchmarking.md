# Домашнее задание №3: Бенчмаркинг продукта

## 3. Анализ и сравнение

### 3.1. Обязательные функции (исходя из анализа конкурентов)

На основе анализа Brand Analytics, Медиалогии и других игроков выделены функции, без которых продукт не может выходить на рынок:

| Функция | Обоснование |
|---------|-------------|
| **Мониторинг упоминаний из соцсетей и СМИ** | Присутствует у всех конкурентов. Brand Analytics покрывает VK, Telegram, OK, Rutube, YouTube, СМИ. Медиалогия — 109 000 источников. Это базовый стандарт |
| **Анализ тональности (Sentiment Analysis)** | Все лидеры используют AI/NLP. Пользователи прямо называют это ключевой ценностью |
| **Гео-карта с региональной аналитикой** | Brand Analytics предоставляет интерактивную карту сравнения тем по регионам. Медиалогия позволяет фильтровать данные по городам. Это стандарт визуализации |
| **Real-time или near real-time сбор данных** | Пользователи хвалят Медиалогию за «данные через 2 минуты». Brand Analytics обеспечивает непрерывный мониторинг |

### 3.2. Функции для отличия от конкурентов

| Наше отличие | Почему это ценно |
|--------------|------------------|
| **Легальность данных «из коробки»** | Мы используем только официальные API (Reddit, Rutube, RSS). Конкуренты собирают данные из VK, Telegram, OK, что несёт риски нарушения ToS |
| **Гибридный алгоритм оценки тональности** | NLP-модель + учёт пользовательских реакций (лайки, репосты). Это повышает точность по сравнению с чисто лингвистическим анализом |
| **Фокус на региональную специфику** | NER-извлечение топонимов + регионализмов. У конкурентов — просто фильтры по гео-меткам |
| **Прозрачность источников** | Пользователь видит, с какой платформы пришёл каждый комментарий. У конкурентов источники часто скрыты |

### 3.3. Недостатки конкурентов, которые мы устраняем

| Недостаток (из отзывов) | Наше решение |
|--------------------------|--------------|
| **Высокая стоимость** (общая боль всех лидеров) | Более доступный тариф с полным функционалом |
| **Пропуски в региональных источниках** (Медиалогия) | RSS-ленты региональных СМИ + API локальных платформ |
| **Субъективность оценки тональности** (Медиалогия) | Гибридный алгоритм: NLP + реакции пользователей |
| **Сложная кривая обучения** (YouScan) | Минималистичный UI: строка поиска + карта + одна диаграмма |

### 3.4. Наиболее эффективные стратегии монетизации

На основе анализа рынка подтверждено: модель **«единый функционал — оплата за объём»** (как у Brand Analytics) является наиболее эффективной. Исторический кейс IQBuzz показывает, что урезание функций на младших тарифах ведёт к потере конкурентоспособности.

### 3.5. Улучшение пользовательского опыта (UX)

| Аспект UX | Текущая ситуация | Наше улучшение |
|-----------|------------------|----------------|
| **Скорость первого результата** | Медиалогия: до 5 мин. Интерфакс: 1 мин. Крибрум: 15 сек. | Цель: ≤ 1 минута от запроса до карты |
| **Простота интерфейса** | YouScan: сложная кривая обучения. Медиалогия: перегруженный интерфейс | Одна строка поиска → карта → одна диаграмма |
| **Прозрачность данных** | Конкуренты: источники — «чёрный ящик» | Каждый комментарий имеет метку источника |
| **Цена** | Высокая стоимость (общая боль пользователей) | Доступный тариф с полным функционалом |

### 3.6. Ключевые характеристики для конкурентоспособности

| Характеристика | Почему критично |
|----------------|-----------------|
| **Легальность данных** | Устраняет риск блокировок и судебных исков |
| **Точность анализа тональности (F1 ≥ 0.85)** | Пользователи называют точность ключевой ценностью |
| **Гео-покрытие ≥ 80% субъектов РФ** | Наше главное позиционирование — «Карта реакций» |
| **Время ответа ≤ 1 минуты** | Быстрее, чем у конкурентов |
| **Прозрачная модель монетизации** | Один тариф — весь функционал |

## 4. Определение стандартов

### 4.1. Минимальные требования к функциональности

1.  Сбор упоминаний минимум из 3 источников (Reddit API, Rutube API, RSS-ленты).
2.  Анализ тональности с точностью F1 ≥ 0.70 (минимальный порог) / 0.85 (целевой).
3.  Интерактивная гео-карта РФ с цветовой индикацией тональности.
4.  Время получения сводки ≤ 5 минут.
5.  Адаптивный веб-интерфейс (мобильные устройства).

### 4.2. Ключевые конкурентные преимущества

1.  **Юридическая чистота:** только официальные API.
2.  **Гибридный анализ тональности:** NLP + социальные реакции.
3.  **Региональная глубина:** NER + регионализмы.
4.  **Прозрачность источников.**
5.  **Доступная цена:** полный функционал на одном тарифе.

### 4.3. Оптимальная модель ценообразования и монетизации

**Модель:** SaaS-подписка, оплата за объём данных (сообщений в месяц).  
**Обоснование:** Подтверждена рынком (Brand Analytics). Позволяет обслуживать и малый бизнес, и enterprise на одном продукте.  
**Ценовой ориентир:** Ниже Brand Analytics (35 000 ₽) для стартового тарифа. Возможно, 15 000–25 000 ₽/мес для MVP.

### 4.4. Минимальные показатели (Бенчмарки)

Итоговая строка Benchmark из Google-таблицы:

| Показатель | Целевое значение | Обоснование |
|------------|------------------|-------------|
| **Точность анализа тональности (F1-score, weighted)** | ≥ 0.85 | Выше среднего по рынку. Ориентир на лидеров (Brand Analytics, YouScan) |
| **Скорость сбора данных** | ≤ 2 минут | Стандарт, заданный Медиалогией |
| **Гео-покрытие** | ≥ 80% субъектов РФ | Наше ключевое позиционирование |
| **Время получения сводки (Time-to-Insight)** | ≤ 1 минуты | Ориентир на Интерфакс (1 мин) и Крибрум (15 сек) |
